IKIHEALING Hub

Hệ điều hành nội bộ cho doanh nghiệp bán lẻ nhỏ, khoảng 5 đến 50 người. Một chỗ gom chấm công, lương, KPI, việc, khách, đơn hàng, nội dung, quảng cáo, báo cáo và một đội trợ lý AI chạy nền. Tách ra từ hệ thống một công ty đang vận hành thật mỗi ngày.

Bản chia sẻ chỉ chứa dữ liệu mẫu của một công ty giả tên ACME Corp. Không có khách hàng, đơn hàng, giá bán hay nhân sự thật nào trong mã nguồn.

Nguồn bên ngoài đổ vào, máy chuẩn hoá về một kho chung, trợ lý AI đọc kho để soạn việc. Chỉ thứ đã qua cổng mới tới được khách hoặc đụng tới tiền.

Nguồn

  • Nhóm chat ghi đơn

Dùng thử

Cài trên máy khoảng 15 phút

Cần Node.js 20, Docker và Supabase CLI. Mở lên đã có sẵn một công ty mẫu với khách, lead, khoảng 450 đơn trong 90 ngày, việc và chấm công.

Lệnh cài

git clone https://github.com/hopecorp-cpu/ikihealing-hub.git
cd ikihealing-hub
npm install
supabase start
supabase db reset
cp .env.example .env.local
npm run dev

Điền 3 khoá Supabase vào .env.local theo README rồi mở localhost:3000.
